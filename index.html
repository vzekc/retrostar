RetroStar-Pakete

Das apt-Repository des RetroStar für Debian und Raspberry Pi OS, bookworm und trixie, auf amd64, arm64 und armhf:

  • retrostar-client — die Verbindung zum RetroStar
  • latd — LAT-Server
  • mopd — MOP-Loader

Den Client richtet das Installationsskript ein, zusammen mit diesem Repository:

bash -c "$(curl -fsSL https://retrostar.classic-computing.de/install.sh)"

Von Hand:

sudo curl -fsSLo /etc/apt/keyrings/retrostar.gpg https://vzekc.github.io/retrostar/retrostar-archive-keyring.gpg
. /etc/os-release
sudo tee /etc/apt/sources.list.d/retrostar.sources <<EOD
Types: deb
URIs: https://vzekc.github.io/retrostar/
Suites: $VERSION_CODENAME
Components: main
Signed-By: /etc/apt/keyrings/retrostar.gpg
EOD
sudo apt update
